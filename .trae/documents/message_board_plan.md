# 前后端分离留言板Demo项目计划

## 项目概述
创建一个简单的前后端分离的在线留言板demo项目，使用React作为前端技术栈，Go作为后端技术栈。项目不需要用户系统和鉴权功能，整体设计越简单越好。

## 技术栈
- 前端：React
- 后端：Go
- 数据存储：SQLite（使用纯Go实现的SQLite库，不依赖cgo）
- 通信：HTTP RESTful API

## 核心功能

### 前端功能
1. **留言列表**：展示所有留言
2. **新增留言**：提交新的留言内容

### 后端功能
1. **获取留言列表**：返回所有留言数据
2. **创建新留言**：接收并存储新留言

## API设计

### GET /api/messages
- 功能：获取所有留言
- 响应：JSON数组，包含所有留言对象

### POST /api/messages
- 功能：创建新留言
- 请求体：JSON对象，包含留言内容
- 响应：创建成功的留言对象

## 实现步骤

### 1. 初始化前端项目
- 使用Vite创建React项目
- 安装必要依赖

### 2. 实现前端组件
- 创建MessageList组件：展示留言列表
- 创建MessageForm组件：提交新留言
- 实现API服务：与后端通信

### 3. 初始化后端项目
- 创建Go模块
- 实现HTTP服务器
- 实现API路由和处理函数

### 4. 实现后端逻辑
- 实现SQLite数据库初始化和表结构创建
- 实现留言数据结构
- 实现获取留言列表的处理函数
- 实现创建新留言的处理函数

### 5. 测试和运行
- 启动后端服务器
- 启动前端开发服务器
- 测试留言功能

## 注意事项
- 使用纯Go实现的SQLite库（如modernc.org/sqlite），不依赖cgo
- 数据存储在SQLite数据库文件中，重启服务后数据不会丢失
- 不实现用户系统和鉴权功能
- 前端使用简单的样式，不引入复杂的UI库
- 后端使用Go标准库实现HTTP服务，不引入框架

## 预期效果
- 前端页面展示留言列表
- 用户可以在表单中输入留言内容并提交
- 提交后，新留言会显示在列表中
- 页面会自动刷新留言列表
